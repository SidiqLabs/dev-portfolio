# Sidiq Kusumah — Frontend Portfolio

Personal frontend engineering portfolio built to showcase my projects, technical skills, engineering approach, and progression toward professional frontend software engineering.

## Overview

This portfolio is built with a design-system-driven approach and focuses on responsive interfaces, maintainable architecture, accessibility, performance awareness, and polished user interactions.

The project follows a modular structure with section-level components, reusable UI primitives, centralized content data, and controlled styling scope.

## Tech Stack

- Next.js 15 with App Router
- React 19
- TypeScript
- Tailwind CSS v4
- Radix UI / shadcn-style UI primitives
- Motion
- React Hook Form
- Zod
- EmailJS
- clsx
- tailwind-merge

## Main Sections

- Hero
- Who Am I
- Statistics
- Career Journey
- Core Skills
- FAQ
- Why I Stand Out
- Projects
- Testimonials
- Contact
- Footer

## Engineering Approach

The project follows several core principles:

- Component-based architecture
- Centralized content through constants
- Controlled local and global styling scope
- Responsive design discipline
- Reusable UI primitives where reuse is justified
- Accessibility-conscious implementation
- Performance-aware frontend development
- Clean and maintainable TypeScript code

Local Development

Install dependencies:

npm install

Run the development server:

npm run dev

Create a production build:

npm run build

Run the production server:

npm run start
Environment Variables

The contact form uses EmailJS.

The required environment variables are kept outside source control and must be configured locally or in the deployment environment.
